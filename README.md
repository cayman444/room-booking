# Система бронирования переговорных комнат

Одностраничное веб-приложение (SPA) для поиска, бронирования и управления переговорными комнатами в офисах компании. Реализовано в рамках тестового задания.

## Инструкция по установке и запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/cayman444/room-booking.git
cd room-booking
```

### 2. Запуск сервера (терминал 1)

```bash
cd server
npm install
npm run dev
```

Сервер будет доступен по адресу `http://localhost:3000`.  
Документация Swagger UI доступна по адресу `http://localhost:3000/documentation`.

### 3. Запуск клиентского приложения (терминал 2)

```bash
cd client
npm install
npm run dev
```

Клиентское приложение откроется по адресу `http://localhost:5173`.

## Запуск тестов и проверка качества кода

### Запуск unit-тестов клиента

```bash
cd client
npm run test:run
```

### Проверка линтером (ESLint)

```bash
cd client
npm run lint
```

## Стек технологий

- **Фреймворк и язык:** React, TypeScript
- **Сборщик:** Vite
- **Стилизация и дизайн-система:** Tailwind CSS, Lucide React, Google Fonts (Manrope)
- **UI-примитивы:** Shadcn UI
- **Управление серверным состоянием:** TanStack Query (React Query)
- **Маршрутизация:** React Router
- **Работа с формами и валидация:** React Hook Form, Zod
- **Работа со временем и датами:** date-fns, Intl API
- **Уведомления:** Sonner (интерактивные тосты)
- **Тестирование:** Vitest, Testing Library

## Архитектура проекта

```
client/src/
├── app/                    # Инициализация приложения, роутинг, провайдеры, глобальные лейауты
│   ├── layouts/            # RootLayout с подключением WebSocket и Toaster
│   ├── providers/          # QueryClientProvider
│   └── routes/             # Конфигурация маршрутов (React Router)
│
├── pages/                  # Страницы приложения (композиционный слой)
│   ├── RoomsPage           # Каталог переговорных с фильтрами и выбором офиса
│   ├── roomDetailPage      # Страница комнаты с 15-минутной сеткой расписания
│   ├── myBookingsPage      # Список бронирований текущего пользователя
│   └── NotFoundPage        # Страница 404 с удобной навигацией
│
├── widgets/                # Крупные самодостаточные блоки интерфейса
│   ├── header              # Шапка сайта с навигацией, профилем и мобильным бургером
│   ├── availableRooms      # Список доступных переговорных, скелетоны, ошибки и пустые состояния
│   ├── roomSchedule        # Интерактивное дневное расписание 09:00–20:00 с таймслотами
│   └── myBookings          # Вкладки и список бронирований пользователя
│
├── features/               # Пользовательские сценарии и бизнес-действия
│   ├── select-office       # Выбор активного офиса с расчетом местного времени
│   ├── filter-rooms        # Фильтрация комнат по дате, времени, длительности и вместимости
│   ├── book-room           # Модальное окно бронирования с Zod-валидацией и 409-конфликтами
│   └── cancel-booking      # Модальное окно подтверждения отмены брони
│
├── entities/               # Бизнес-сущности
│   ├── user                # Модель текущего пользователя и карточка в шапке
│   ├── office              # API и типы офисов
│   ├── rooms               # API комнат, карточки, бейджи вместимости и удобств
│   └── bookings            # API бронирований, форматирование карточек броней
│
└── shared/                 # Переиспользуемый инфраструктурный код
    ├── api/                # Axios-инстанс apiClient, обработчики ошибок
    ├── config/             # Константы роутов и URL Search Params
    ├── lib/                # Утилиты дат (date-fns), таймзон, realtime-хук (useRealtime)
    └── ui/                 # UI-кит
```
